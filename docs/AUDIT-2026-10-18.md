## Outstanding source-level gaps

- Native STB profile storage currently contains name, portal and MAC; optional owner-supplied serial/device fields and STB history require separate work.
- Managed Sheet enrichment reconstructs base StreamItem values; typed Series/Episode preservation needs a focused regression test and fix before managed series can be called complete.
- Full XMLTV ingestion/TV guide, expanded aspect/pan controls, local subtitle picker/delay/style settings, next/previous episode and Settings cache management are incomplete or not wired.
- Movie/Episode fallback correction: HTTP/network failures no longer trigger alternate decoders; codec/container errors alone qualify. When the LibVLC bridge cannot carry all required headers, IJK receives the full map. Unit and physical validation of this correction are separate.
- Existing subtitle translation is not yet physically verified end-to-end. Transcription must remain a separate fallback after proving existing-subtitle translation; it must never run merely because an existing track is unsupported by extraction.
- API 23, Android 13–16, Samsung S23, Fire TV, D-pad, background/relaunch, memory/resource cleanup, GPS/weather, activation and release signing need actual device/emulator evidence at the delivered commit.
